# Task Manager

This is a task manager application where users can add, delete, and mark tasks as complete. It helps users organize their tasks and keep track of what they need to do.

## Features

- Add new tasks
- Save tasks using localStorage
- Filter tasks by All, Active, and Completed
- Edit existing tasks
- Mark tasks as complete
- Delete tasks
- Search tasks
- Clear completed tasks

## Technologies Used

- HTML
- CSS
- JavaScript

- localStorage
- Filtering arrays
